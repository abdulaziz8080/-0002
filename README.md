# ملتزم (Multazim)

منصة لمكاتب المحاسبة والمعقّبين لمتابعة الالتزامات والتجديدات النظامية لمنشآت عملائهم في السعودية،
مع تذكيرات يومية تُرسل تلقائياً من **واتساب المكتب نفسه**.

كل منشأة عندها أكثر من ١٢ التزاماً يتجدد دورياً عبر جهات مختلفة (وزارة التجارة، بلدي، الزكاة
والضريبة والجمارك، الموارد البشرية، التأمينات، الجوازات، الدفاع المدني) — ولا جهة منها ترسل
تذكيراً موحداً. ملتزم يجمعها في لوحة واحدة لكل مكتب، يحسب حالة كل التزام، ويرسل التذكيرات قبل الموعد.

## المكوّنات

| المسار | الوصف |
| --- | --- |
| `src/` | واجهة Next.js (صفحة الهبوط، تسجيل الدخول، لوحة التحكم، شاشة ربط واتساب/QR) |
| `server/` | خادم Express + Prisma (SQLite): حسابات المكاتب، المنشآت، الالتزامات، جلسات واتساب، Cron التذكيرات |
| `server/src/lib/whatsapp.ts` | جلسة WhatsApp Multi-Device مستقلة لكل مكتب عبر [Baileys](https://github.com/WhiskeySockets/Baileys)، محفوظة في `server/data/wa/<officeId>` |
| `server/src/lib/reminders.ts` | منطق الفحص اليومي وبناء الرسالة ومنع التكرار (`ReminderLog`) |
| `src/lib/obligations.ts` | كتالوج الالتزامات النظامية ودورات تجديدها ومهل التنبيه |

## التشغيل محلياً

```bash
npm run setup                 # يثبّت الواجهة والخادم وينشئ قاعدة البيانات
cp server/.env.example server/.env   # عدّل JWT_SECRET
cp .env.example .env.local
npm run dev:all               # الواجهة على :3000 والخادم على :4000
```

ثم افتح <http://localhost:3000>، أنشئ حساب مكتب، وادخل تبويب **واتساب والتنبيهات** لعرض QR ومسحه من جوال المكتب
(واتساب ← الأجهزة المرتبطة ← ربط جهاز).

### إعدادات الخادم (`server/.env`)

| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `DATABASE_URL` | `file:./data/multazim.db` | قاعدة SQLite |
| `JWT_SECRET` | — | سرّ توقيع التوكن (غيّره) |
| `PORT` | `4000` | منفذ الخادم |
| `REMINDER_CRON` | `0 8 * * *` | موعد الفحص اليومي |
| `TZ` | `Asia/Riyadh` | المنطقة الزمنية للـ Cron وحساب "اليوم" |
| `WA_AUTH_DIR` | `./data/wa` | مجلد جلسات واتساب (حساس — لا يُرفع للمستودع) |
| `CORS_ORIGIN` | `http://localhost:3000` | رابط الواجهة |

### التذكيرات

- يفحص Cron يومياً كل الالتزامات غير المنجزة ويرسل رسالة مجمّعة لأرقام المكتب (`alertPhones`) عند: قبل ٣٠/١٤/٧ أيام، يوم الاستحقاق، ويومياً أثناء التأخر، إضافة إلى بداية مهلة التنبيه الخاصة بكل التزام.
- لا يُرسل التذكير نفسه مرتين لنفس الرقم (قيد فريد على `itemId + milestone + to`).
- اختيارياً تُرسل نسخة لرقم مسؤول كل منشأة (`notifyOrgContacts`).
- تشغيل يدوي: `cd server && npm run remind:now -- --dry` أو زر «تشغيل الفحص الآن» في اللوحة.

## تنبيه

المعلومات في كتالوج الالتزامات إرشادية لأغراض التذكير فقط، ولا تُغني عن مراجعة الجهة المختصة.
Baileys مكتبة غير رسمية تعتمد على WhatsApp Web؛ استخدم رقم أعمال مخصصاً للمكتب.
